# Soroban Cookbook - Tokens Category

This category contains cookbook recipes and example contracts demonstrating how to implement and extend token standards on Stellar's Soroban smart contract platform.

## Examples

- **[04-snapshot-token](./04-snapshot-token)**
  A complete SEP-41-style fungible token with efficient snapshot balance tracking. It implements the sparse-snapshot pattern to record point-in-time balance snapshots, which are essential for historical queries and decentralized governance voting-power calculations.
