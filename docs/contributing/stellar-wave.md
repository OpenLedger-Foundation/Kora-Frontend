# Stellar Wave (archived)

> The open-source Stellar Wave contribution program for this repository has ended.
> This page is kept as historical reference for past contributors and maintainers.
> For current contribution guidance, see [CONTRIBUTING.md](../../CONTRIBUTING.md).

During the Wave, work was tracked with the `Stellar Wave` label. Merged pull
requests earned points paid out through [Drips](https://www.drips.network/).

## Historical workflow

1. Find an open, unassigned Wave issue.
2. Comment to apply and wait for maintainer assignment before opening a PR.
3. Branch from latest `main` using the issue’s suggested name or a standard prefix.
4. Run `npm run lint && npm run type-check && npm run test && npm run build`.
5. Open a PR that includes `Closes #<issue_number>` in the description.

### Complexity and points (historical)

| Complexity | Points | Typical scope |
| ---------- | ------ | ------------- |
| Low        | 50     | Docs, copy, a single small component |
| Medium     | 100    | One feature or test suite in a single module |
| High       | 200    | Engineering work touching multiple modules |

### Wave rules (historical)

- Assignment before starting.
- One issue at a time unless a maintainer said otherwise.
- Quiet for a week could mean unassignment.
- UI changes needed screenshots or a recording in the pull request.
